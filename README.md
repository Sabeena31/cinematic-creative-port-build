# Sabeena Portfolio

Build the complete personal portfolio website from scratch exactly as specified: Sabeena Kachary’s cinematic, art-directed cybersecurity + GRC + design portfolio. Implement the full responsive React/Vite/Tailwind website, all sections and interactions, supplied three-video crossfading hero with blob preloading and graceful fallbacks, accessible/reduced-motion behavior, real project links, honest project content, and a clean successful production build. Do not use Viktor or Davies anywhere, do not invent personal contact details or achievements, and do not stop at the hero.
